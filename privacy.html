Privacy policy

Last updated November 26, 2026

Ouro is software you run on your own computers. There's no Ouro cloud service that collects your data.

Google user data (Gmail)

The "Ouro Gmail" Google app is used only by its owner. When it's connected, agents on the owner's own computer use the Gmail API to search and read messages, list labels, create drafts, and send email the owner has approved.

  • Its sign-in tokens are stored only on the owner's computer, in files only the owner can read.
  • Email isn't stored on any server, sold, or shared with third parties. The only exception is the AI model that the owner's agents use, which reads email content to do the task the owner asked for.
  • It isn't used for advertising, and it isn't used to train AI models.
  • The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

To disconnect, remove "Ouro Gmail" at myaccount.google.com/permissions and delete the local token file.
